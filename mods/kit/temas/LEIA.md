# Temas

- **O que faz:** temas para os apps do Claude Code (Dunas, o padrão, com a cena das dunas e vidro fosco; Kit, Café, Meia-noite, Floresta, Neon e Papel). `/tema` abre o seletor.
- **Detalhes:** [README.md](README.md). A cena das dunas é copiada do theme-examples (`LICENSE-theme-examples`).
- **Testes:** `claude plugin test mods/kit/temas`.
