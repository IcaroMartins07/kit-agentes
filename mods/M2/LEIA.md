# M2 · You Should Know

- **Origem:** Anthropic, embutido no Claude Code. Não há código para guardar aqui.
- **O que faz:** um agente auxiliar acompanha tarefas longas e mostra, acima do prompt, notas sobre detalhes que você ou o Claude podem ter deixado passar.
- **Ativar:**
  ```
  /plugin enable cc-plugin-you-should-know@builtin
  ```
  Também aparece em `/plugin`, aba Installed, entre os itens Built-in desativados.
- **Atenção:** opcional. Exige sessão direta com a Anthropic e telemetria ativa. A análise consome uso adicional.
